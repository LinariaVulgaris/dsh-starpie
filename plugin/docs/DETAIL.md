# 星盘(Astrolabe)

在 DeepSeek Harness 的会话界面中,右键(或 Shift+F10 之外的鼠标右键手势)会在指针处弹出一个环形菜单,把常用操作放到一次点击之内。

## 用法

- 在对话区域任意位置右键,环形菜单以指针为中心展开。
- 悬停某个扇区查看说明;点击执行;点击中心圆或按 Esc 关闭;方向键选择、Enter 执行。
- 全部自定义都在**设置面板的「星盘」分区**:勾选要显示的功能、用箭头调整顺序、选择右键触发范围(仅对话区域 / 整个页面)、调整圆盘大小、弹出时长、液态玻璃质感(见下)、动效强度与主题颜色。保存后立即生效,并持久化到当前 profile。环上不再保留「自定义菜单」扇区,槽位全部留给业务功能。
- 菜单以「放大晕开」动效出现:圆盘由小放大弹出(带过冲回弹),各扇区图标依次错峰浮现;关闭时圆盘缩回中心(不再有涟漪水波)。面板「动效强度」三档:Q 弹(默认,始终播放完整动画)、轻柔(仅缩放淡入、无回弹、无水波)、跟随系统(系统开启减弱动态效果时自动降为轻柔)。
- 圆盘固定为**液态玻璃**质感(不再提供风格切换):重度模糊配适度饱和度,中性乳白蒙版上密下透(模拟自上打光),边缘是克制的镜面反光环而非硬倒角;素材克制、无对角高光。盘面、中心圆与扇区悬停态共用一套结构,深色与浅色只替换一组 `--lq-*` 配方变量。
- 设置面板里有「**液态玻璃微调**」分组,7 个滑钮:模糊强度、饱和度、亮度、底色浓度、镜面高光、分割线、雾面光泽。每个滑钮都是相对默认配方的倍率(100% 即原始调校),点「保存」后即时生效并随配置持久化;点「恢复默认」把全部滑钮一并复位到 100%。
- 分组上方是「**实时预览**」:一块按真实圆盘的同结构、同配方、同尺寸渲染的样例(底下垫着模拟页面内容的彩色背景)。拖动任一滑钮,或改动圆盘大小、弹出时长、动效强度、主题颜色、菜单项勾选与排序,预览即时可见;点击预览区(或「重播动画」按钮)按当前时长与动效档位重放入场动画,悬停扇区同样会点亮。预览只反映面板中的草稿状态,点「保存」后才会作用到真正的右键菜单。

## 内置功能

| 功能 | 行为 |
| --- | --- |
| 插件市场 | 打开设置面板并进入「插件市场」分区(dsh-market 贡献的市场页) |
| 设置分区(动态) | 自定义面板会自动列出设置面板里的全部分区行(内置的与已安装插件贡献的,如账号与余额、通用设置、手机访问、Our Free Model、壁纸引擎等,也包括「星盘」自身),勾上即作为环上的一个扇区,点击直达对应分区。插件被卸载或禁用后,其分区扇区会自动从环上和面板列表中消失;插件重新启用后扇区自动恢复,在面板中点「保存」时才会把失效项永久写掉。与固定功能重复的分区会被跳过——「插件市场」分区已由同名固定项覆盖,不再重复列出。分区图标为本插件手写的字形(设置面板导航栏不对外暴露图标数据),未收录的分区使用齿轮轮廓 |
| 新会话 | 在当前工作区开始一个新会话 |
| 打开目录 | 在系统文件管理器中打开会话工作目录 |
| 复制路径 | 把会话工作目录的完整路径写入剪贴板 |
| 重启 DSH | 退出当前 DeepSeek Harness 并以原方式重新拉起。点击后先弹确认框(仅此一项有确认):说明会立即中断所有运行中的任务与 AI 输出,当前会话正在生成时额外红字提醒,并区分桌面版/Web 版的重启表现;确认后才执行。Web 版:Host 派生脱离的看门狗等待退出后按原命令重启,新实例沿用原终端输出监听地址;Desktop 版:看门狗在 Host 退出后结束 Electron 外壳(释放单实例锁),再以普通 GUI 方式重新启动应用;SSH 环境返回不可用提示 |

悬停任一扇区时,圆盘中心会同步显示该扇区的图标,与扇区本身使用同一套图标解析(分区项也一样);无悬停时显示关闭叉号。

## 限制

- 「插件市场」扇区通过模拟点击左下角头像菜单打开设置面板(与手动操作同一路径);找不到头像菜单时回退为合成「打开设置」快捷键按键(仅 Web 版可用,Desktop 版快捷键走原生通道)。
- 「插件市场」先打开设置面板,再按分区行文字点进「插件市场」;面板约 2.5 秒内未渲染出该分区时会提示失败。
- 配置保存在 profile 目录的 `dsh-radial-menu.json`;无 profile 的环境(如纯 headless)中保存会返回失败提示,菜单仍按默认配置工作。
- 「重启 DSH」会中断当前进程内的所有会话与任务,重启后需重新打开页面;旧配置文件中没有该项时会自动在环尾追加一次。Desktop 版的重启会强制结束 Electron 外壳(未保存的窗口状态不保留),约数秒后应用自动重新打开。
