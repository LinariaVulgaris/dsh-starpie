# 星盘 · StarPie

[English](README.md) | 简体中文

> **致谢** —— 本插件的灵感来源于 [StarPie](https://github.com/Star-Pie/StarPie)（一个现代化的 Windows 鼠标轮盘手势系统），并针对 DeepSeek Harness 的 Web 界面做了独立实现。

DeepSeek Harness（DSH）Web 界面的右键环形菜单插件。

在会话区域点右键，指针处会展开一个液态玻璃圆盘，把你真正常用的动作放在一次点击之内：插件市场、新会话、打开工作区目录、复制目录路径、重启 DSH 本身——以及你想要的任意设置分区，包括其他插件贡献的分区。

圆盘的一切都可以在插件新增的「**星盘**」设置分区里配置：显示哪些功能、它们的顺序、右键触发范围、圆盘大小、弹出时长、七项带实时预览的液态玻璃滑钮、动效强度与主题颜色。

## 环境要求

- 带 Web 界面的 DeepSeek Harness，浏览器或桌面客户端都可以。开发与测试基于 **DSH 0.2.2-rc.3**。插件没有声明 `engines.dsh` 范围，因此安装不做版本门禁；但如果将来某个 DSH 版本改动了本插件挂接的设置面板或 slot 接口，相关功能可能需要跟着调整。
- 一个受管理的 profile。配置按 profile 存储。在没有 profile 的环境里，保存会报失败，圆盘则继续按默认值工作。
- 无依赖、无构建步骤。插件就是纯 ES module 加一段注入的 CSS；React 由 DSH 的客户端模块加载器提供。

## 安装

打开 DSH 侧边栏的「**插件**」页，点「**添加插件**」（或它旁边的箭头，再选「**安装第三方插件**」）。输入框接受包名、Git 地址、tarball 或本地绝对路径：

| 来源 | 填什么 |
| --- | --- |
| GitHub | `github:LinariaVulgaris/dsh-starpie` 或 `https://github.com/LinariaVulgaris/dsh-starpie.git` |
| 本地克隆 | 克隆目录的绝对路径，例如 `D:\code\dsh-starpie` 或 `/home/you/code/dsh-starpie` |

也可以走命令行：

```bash
git clone https://github.com/LinariaVulgaris/dsh-starpie.git
dsh plugin --profile <name> add /absolute/path/to/dsh-starpie
```

Agent 也能装：用 `plugin_manager` 工具的 `install_bundle`，target 填 `github:LinariaVulgaris/dsh-starpie`。`plugin_manager` 的每个动作都需要 `danger-full-access` 或单次调用的批准。

安装后插件默认启用，出现在「**已安装插件**」里，名字是 *StarPie*（星盘），同时给设置面板加一个「**星盘**」分区。开启 HMR 时立即生效；没开 HMR 则要等 DSH 重启后才会载入新的组合。

### 升级

从 Git 装来的插件不会显示「**版本**」区块。如果当初的 spec 钉的是完整的 40 位 commit，插件页会提供 Git 升级；钉的是分支或 tag 就无法升级，只能卸载后重新安装新版本。配置存在 profile 里，两种方式都不会丢。如果你装的是旧名字 `@local/dsh-radial-menu` 的版本，请先移除旧条目——见「[说明与限制](#说明与限制)」。

## 用法

- 在会话区域点右键（把触发范围放宽后，页面任意位置都行）。圆盘以指针为中心展开，并会自动收缩到屏幕内。
- 鼠标悬停某个扇区可以看到它的说明——标签显示在环上，图标移到圆盘中心。点击即执行。
- 键盘：方向键移动选中项，Enter 执行，Esc 关闭；点击中心圆盘同样关闭。圆盘打开时会在自己下方显示这些按键提示，悬停某个扇区时换成该扇区的说明。
- 窗口 resize 或失焦时圆盘关闭；在有明确滚动手势后 300 ms 内发生的滚动也会关闭它。
- 只有主视图中存在会话时圆盘才会弹出；当前没有打开任何会话时，右键不会有反应。

## 配置

打开「**设置 → 星盘**」。在按下「**保存**」之前，真实的圆盘不会有任何变化；保存后立即生效，并持久化到当前 profile。

| 控件 | 作用 |
| --- | --- |
| 右键触发范围 | *仅对话区域*（默认），或 *整个页面(输入框除外)*——后者同样会避开可编辑区域、输入器、已有的上下文菜单，以及圆盘自己的图层 |
| 圆盘大小 | 140–320 px，默认 200 |
| 弹出时长 | 120–900 ms，默认 380 |
| 实时预览 | 用真实圆盘的结构、配方和尺寸，在模拟页面背景上渲染的样例。滑钮即时反映到预览；点击预览或「**重播动画**」可以按当前时长与动效档位重放入场动画。预览跟随面板里未保存的草稿状态 |
| 液态玻璃微调 | 相对默认配方的七个倍率——模糊强度、饱和度、亮度、底色浓度、镜面高光、分割线、雾面光泽。100% 即完全还原默认调校 |
| 动效强度 | *Q 弹*（始终播放完整动画）、*轻柔*（只缩放淡入，无过冲）、*跟随系统*（系统要求减少动效时自动降为轻柔） |
| 主题颜色 | 十个预设（默认青色），外加一个自定义 `#rrggbb` 取色器 |
| 菜单功能与顺序 | 已勾选的功能在上，用 ↑ / ↓ 调整顺序；未勾选的列在下方，随时可以加进来。勾选即追加到末尾 |
| 恢复默认 | 底部按钮，最左侧。把上面所有设置一次性复位，不只是那七个滑钮 |
| 点个 Star | 底部按钮，在「**保存**」左边。调用本机默认浏览器打开本仓库页面；如果够不到本机浏览器（例如 SSH 远程），则退化为在你正在用的浏览器里新开一个标签页。两条路都走不通时，底部会给出提示 |

功能列表不止五个内置项。设置面板里注册的每一个分区——内置的和其他插件贡献的——都会作为一个可勾选的行出现，勾上就成为直达该分区的扇区。「**插件市场**」已经覆盖的那一个分区不会出现在列表里，因此不会被重复添加。插件被卸载或禁用后，它的分区行会从圆盘和列表里一起消失；重新启用插件后自动恢复，而失效项只有在你点「**保存**」时才会被永久写掉。

## 内置功能

| 功能 | 行为 |
| --- | --- |
| 插件市场 | 打开设置面板并定位到「**插件市场**」分区 |
| 设置分区（动态） | 每个勾选的设置分区一个扇区，点击直达 |
| 新会话 | 在当前工作区开一个新会话 |
| 打开目录 | 用系统文件管理器打开会话的工作区目录（`explorer`、`open` 或 `xdg-open`） |
| 复制路径 | 把工作区目录的完整路径写入剪贴板 |
| 重启 DSH | 退出 DeepSeek Harness 并按原来的方式重新拉起。唯一带确认弹窗的功能 |

「**重启 DSH**」值得单独说明。弹窗会警告所有正在运行的任务和进行中的 AI 输出都会被立即中断，当前会话正在生成时额外给出一条红色警告，并写明两种宿主的区别：

- **Web** —— Host 会先派生一个脱离进程的看门狗，等进程退出后重新执行原来的命令，新实例继续监听原终端提供的那个地址。
- **桌面端** —— 看门狗在 Host 退出后终止 Electron 外壳（从而释放单实例锁），再以普通 GUI 的方式重新启动应用。未保存的窗口状态不会保留。

在 SSH 环境下，该功能会直接报告不可用，而不是重启。

## 扇区图标是硬编码的

圆盘上的每一个图标都是手写并**硬编码**在 `client.js` 里的：运行时不联网获取，插件也不附带任何图标字体或图片资源。

- `ICON_PATHS` 把字形名映射到一段 SVG path 字符串，统一画在 24×24 的 viewBox 中。字形只用描边；圆盘中心的两个状态徽标（成功、失败）会在标记下面垫一个填充圆。五个内置功能各用同名字形，其余字形服务于设置分区以及圆盘中心的状态图标（关闭、加载中、成功、失败）。
- `SECTION_ICONS` 把设置分区 id 映射到其中一个字形名。没有收录的分区一律回退为齿轮轮廓。
- 设置面板的导航不对外暴露任何图标数据（`settings.section.icon` 没有占用者，外壳自己绘制导航字形），所以这张表无法自动生成——新装插件的分区在被补上映射之前只会显示齿轮。

正因如此，画图标是一件很适合直接交给 agent 做的事。说清楚你想给哪个分区配一个什么字形，让 agent 往 `ICON_PATHS` 里追加一段 24×24 的描边路径，再把 `SECTION_ICONS` 指过去就行；一句「*给 `cost-meter` 设置分区画一个 24×24 纯描边图标，并接进 `client.js` 的 `ICON_PATHS` 和 `SECTION_ICONS`*」这样的提示就够了。字形名写错时会回退为关闭叉号，问题会立刻显形，不会弄坏整个圆盘。

## 说明与限制

- 「**插件市场**」扇区是通过模拟点击左下角头像菜单来打开设置面板的，和用户手动操作走同一条路径。找不到该菜单时，退而合成「**打开设置**」快捷键——这条只在 Web 下可用，桌面端的快捷键走的是原生通道。
- 「**插件市场**」随后按标签文字点击分区行。如果面板在约 2.5 秒内还没渲染出那一行，该功能会报失败。
- 液态玻璃是唯一的质感，没有风格选择器。深色与浅色主题共用同一套结构，只差一组 CSS 配方变量。
- 从旧名字 `@local/dsh-radial-menu` 安装的版本升级时：请先在「插件」里移除旧条目，再安装本插件。两份同时加载会注册两个浮层、两个设置分区和两组 Host 路由。已保存的菜单会自动沿用——当 `dsh-starpie.json` 还不存在时，Host 会去读旧的 `dsh-radial-menu.json`；客户端也会把保存过的 `section:astrolabe` 扇区重定向到改名后的分区 id。旧文件保留在原地、不会被写入，第一次点「保存」时会在它旁边生成新文件。

## 安全性

Host 侧注册四个路由，每个路由在真正干活之前都会先问连接是否应当拒绝这次请求：

- `POST /dsh-starpie/open-dir` —— 要求是已存在的目录的绝对路径，DSH 通过 SSH 启动时直接拒绝。Windows 上还要求路径以盘符开头：`path.win32.isAbsolute()` 会把 `\\host\share` 也算作绝对路径，而对其执行 stat 等于把你的 NTLMv2 质询/响应交给那台主机。它只会拉起平台的文件管理器。
- `GET` / `HEAD` / `PUT /dsh-starpie/config` —— 读写 profile 目录里的一个 JSON 文件，写入是原子的（唯一临时文件、`fsync`、再重命名，并发保存被串行化）。所有值在入口处都被钳制或校验：大小、时长、滑钮范围都有上下界，主题色必须匹配 `#rrggbb`，功能 id 必须是已知内置项，或长度与字符集都受限的 `section:<id>` 短标识——无法识别的分区只是点开时会失败而已。
- `POST /dsh-starpie/restart` —— 终止进程。所以有确认弹窗。
- `POST /dsh-starpie/open-url` —— 用本机默认浏览器打开一个地址。请求里的 URL 会与唯一的白名单值（也就是本仓库页面）做全等比较，因此这个路由不会变成「打开任意 URL」的通用能力；SSH 环境下直接拒绝，客户端随后退化为开浏览器标签页。

没有遥测，也没有统计。插件自身不发出任何外网请求：上面四个路由都由你自己的 DSH Host 在回环地址上提供，它们唯一可能引发的流量，是你的机器自己打开的那个窗口——一个文件管理器窗口，或者你点了「**点个 Star**」之后加载的本仓库页面。除当前会话的工作区目录路径之外，不读取任何会话内容。

## 配置文件

配置以 JSON 存放在当前 profile 目录：

```
<DSH profile 目录>/dsh-starpie.json
```

一般是 `~/.dsh/profiles/<profile>/dsh-starpie.json`。文件里有 `version`、`enabled`、`scope`、`size`、`accent`、`duration`、七个液态倍率、`motion`，以及有序的 `items` 列表。

支持手改，但通常用不上。只有一件事必须靠这个文件：把 `"enabled"` 设成 `false`，可以在不卸载插件的前提下暂停圆盘。在面板里点「**保存**」会把它重新写成 `true`。

## 卸载

「**插件 → 星盘 → 移除**」，确认即可。`dsh-starpie.json` 会留在 profile 里，重新安装后配置还在。

## 实现结构

```
package.json        插件清单：exports、files、dsh.bundle.patch、dsh.client
cordis.patch.yml    把插件的行插入 profile 组合
index.js            Host 侧——注入 `webServer` 的 Cordis 插件，注册上面四个路由
client.js           浏览器侧——经 window.__ModuleLoader__ 加载，注册圆盘与设置分区
locale/en.json      插件页显示用的元数据（英文），含 meta.detail
locale/zh.json      中文版，meta.detail 指向 docs/DETAIL.zh.md
docs/DETAIL.md      插件详情页显示的长描述（英文）
docs/DETAIL.zh.md   中文版
icon.svg            插件图标，手绘
README.md           英文说明
README.zh-CN.md     本文件
CHANGELOG.md        版本记录
LICENSE             MIT
.gitignore          node_modules、dist、日志、系统垃圾文件
```

`client.js` 注入 `slots`、`locale`、`layout`、`shortcuts`、`sessions`。它注册一个渲染圆盘的 `shell.overlay` slot，和一个渲染星盘面板的 `settings.section` slot。所有标记都用 DSH 提供的 React 实例构建；样式表是一个注入的 `<style>` 标签，加载时会自行移除自己那些已被取代的旧版本。

`docs/DETAIL.md` 与 `docs/DETAIL.zh.md` 就是「**插件**」页显示的插件详情文档。插件管理器读取当前语言对应的 `locale/<language>.json` 里 `meta.detail` 指名的文件，找不到时沿语言链回退到英文。
