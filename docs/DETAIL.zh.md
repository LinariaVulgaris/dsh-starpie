# 星盘(StarPie)

在 DeepSeek Harness 的会话界面中右键,会在指针处弹出一个环形菜单,把常用操作放到一次点击之内。

> **致谢** — 本插件的灵感来源于 [StarPie](https://github.com/Star-Pie/StarPie)(一个现代化的 Windows 鼠标轮盘手势系统),并针对 DeepSeek Harness 的 Web 界面做了独立实现。

## 用法

- 在对话区域任意位置右键,环形菜单以指针为中心展开。
- 悬停某个扇区查看说明;点击执行;点击中心圆或按 Esc 关闭;方向键选择、Enter 执行。环打开时会在自己下方显示这些按键提示,悬停某个扇区时换成该扇区的说明。
- 全部自定义都在**设置面板的「星盘」分区**:勾选要显示的功能、用箭头调整顺序、选择右键触发范围(仅对话区域 / 整个页面)、调整圆盘大小、弹出时长、液态玻璃质感(见下)、动效强度与主题颜色。保存后立即生效,并持久化到当前 profile。环上不再保留「自定义菜单」扇区,槽位全部留给业务功能。
- 菜单以「放大晕开」动效出现:圆盘由小放大弹出(带过冲回弹),各扇区图标依次错峰浮现;关闭时圆盘缩回中心(不再有涟漪水波)。面板「动效强度」三档:Q 弹(默认,始终播放完整动画)、轻柔(仅缩放淡入、无回弹、无水波)、跟随系统(系统开启减弱动态效果时自动降为轻柔)。
- 鼠标在扇区之间移动时,选中高亮不再逐格硬切:高亮是一整块沿环滑动的扇形光斑,从一个菜单项平滑滑行到下一个(末项回首项走短弧跨过 0°),移入/移出时淡入淡出;按下时的加亮闪烁同样改为淡入淡出。光斑被径向遮罩限制在扇区环带内(内圈 18% 至外圈 47%),不会溢出圆盘边缘或侵入中心孔。「轻柔」档(或系统减弱动态)只保留淡入淡出,不播放滑行。设置面板里的实时预览同步呈现该效果。
- 圆盘固定为**液态玻璃**质感(不再提供风格切换):重度模糊配适度饱和度,中性乳白蒙版上密下透(模拟自上打光),边缘是克制的镜面反光环而非硬倒角;素材克制、无对角高光。盘面、中心圆与扇区悬停态共用一套结构,深色与浅色只替换一组 `--lq-*` 配方变量。
- 设置面板里有「**液态玻璃微调**」分组,7 个滑钮:模糊强度、饱和度、亮度、底色浓度、镜面高光、分割线、雾面光泽。每个滑钮都是相对默认配方的倍率(100% 即原始调校),点「保存」后即时生效并随配置持久化;「恢复默认」按钮会把全部设置一并复位(功能与顺序、触发范围、圆盘大小、弹出时长、这七个滑钮、动效强度与主题颜色),不只是滑钮。
- 分组上方是「**实时预览**」:一块按真实圆盘的同结构、同配方、同尺寸渲染的样例(底下垫着模拟页面内容的彩色背景)。拖动任一滑钮,或改动圆盘大小、弹出时长、动效强度、主题颜色、菜单项勾选与排序,预览即时可见;点击预览区(或「重播动画」按钮)按当前时长与动效档位重放入场动画,悬停扇区同样会点亮。预览只反映面板中的草稿状态,点「保存」后才会作用到真正的右键菜单。
- 面板底部有三个按钮:最左边「恢复默认」,中间「点个 Star」,最右边「保存」。「点个 Star」通过插件自己的本地路由调用本机默认浏览器打开本插件的 GitHub 仓库页面;如果 Harness 跑在你够不到浏览器的地方(例如 SSH 远程),会退化为在你正在使用的浏览器里新开一个标签页。

## 内置功能

| 功能 | 行为 |
| --- | --- |
| 插件市场 | 打开设置面板并进入「插件市场」分区 |
| 设置分区(动态) | 自定义面板会自动列出设置面板里的全部分区行(内置的与已安装插件贡献的,如账号、通用设置、模型、插件、Agent 预设、费用统计,以及「星盘」自身,还有你其他插件贡献的分区),勾上即作为环上的一个扇区,点击直达对应分区。插件被卸载或禁用后,其分区扇区会自动从环上和面板列表中消失;插件重新启用后扇区自动恢复,在面板中点「保存」时才会把失效项永久写掉。固定项「插件市场」已经覆盖的那一个分区不会列出,因此不会被重复添加。分区图标为本插件手写的字形(设置面板导航栏不对外暴露图标数据),未收录的分区使用齿轮轮廓 |
| 新会话 | 在当前工作区开始一个新会话 |
| 打开目录 | 在系统文件管理器中打开会话工作目录 |
| 复制路径 | 把会话工作目录的完整路径写入剪贴板 |
| 重启 DSH | 退出当前 DeepSeek Harness 并以原方式重新拉起。点击后先弹确认框(仅此一项有确认):说明会立即中断所有运行中的任务与 AI 输出,当前会话正在生成时额外红字提醒,并区分桌面版/Web 版的重启表现;确认后才执行。Web 版:Host 派生脱离的看门狗等待退出后按原命令重启,新实例沿用原终端输出监听地址;Desktop 版:看门狗在 Host 退出后结束 Electron 外壳(释放单实例锁),再以普通 GUI 方式重新启动应用;SSH 环境返回不可用提示 |

悬停任一扇区时,圆盘中心会同步显示该扇区的图标,与扇区本身使用同一套图标解析(分区项也一样);无悬停时显示关闭叉号。

## 扇区图标

环上的每一个图标都是手写并**硬编码**在 `client.js` 里的:运行时不联网获取,插件也不附带任何图标字体或图片资源。

- `ICON_PATHS` 把字形名映射到一段 SVG path 字符串,统一画在 24×24 的 viewBox 中。字形只用描边;圆盘中心的两个状态徽标(成功、失败)会在标记下面垫一个填充圆。五个内置功能各用同名字形,其余字形服务于设置分区以及圆盘中心的状态图标(关闭、加载中、成功、失败)。
- `SECTION_ICONS` 把设置分区 id 映射到其中一个字形名。没有收录的分区一律回退为齿轮轮廓。
- 设置面板的导航不对外暴露任何图标数据(`settings.section.icon` 没有占用者,外壳自己绘制导航字形),所以这张表无法自动生成——新装插件的分区在被补上映射之前只会显示齿轮。

因此新增或替换图标是一次很小、很独立的改动,很适合直接交给 agent 来做:说明你想给哪个分区配一个什么字形,让它往 `ICON_PATHS` 里追加一段 24×24 的描边路径,再把 `SECTION_ICONS` 指过去即可。字形名写错时会回退为关闭叉号,问题会立刻显形,不会弄坏整个环。

## 限制

- 「插件市场」扇区通过模拟点击左下角头像菜单打开设置面板(与手动操作同一路径);找不到头像菜单时回退为合成「打开设置」快捷键按键(仅 Web 版可用,Desktop 版快捷键走原生通道)。
- 「插件市场」先打开设置面板,再按分区行文字点进「插件市场」;面板约 2.5 秒内未渲染出该分区时会提示失败。
- 配置保存在 profile 目录的 `dsh-starpie.json`;无 profile 的环境(如纯 headless)中保存会返回失败提示,菜单仍按默认配置工作。
- 只有主视图中存在会话时环形菜单才会弹出;当前没有打开任何会话时,右键不会有反应。
- 「重启 DSH」会中断当前进程内的所有会话与任务,重启后需重新打开页面;Host 读取 1.0.0 之前的旧配置文件时,若其中没有该项,会自动在环尾追加一次。Desktop 版的重启会强制结束 Electron 外壳(未保存的窗口状态不保留),约数秒后应用自动重新打开。
